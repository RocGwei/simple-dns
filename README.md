# 实现 DNS 服务器

参考 https://github.com/EmilHernvall/dnsguide

## 生成 DNS 请求数据包

```bash
nc -u -l -p 1053 > query_packet.txt

dig +retry=0 -p 1053 @127.0.0.1 +noedns baidu.com

nc -u 8.8.8.8 53 < query_packet.txt > response_packet.txt

hexdump -C query_packet.txt

hexdump -C query_packet.txt
```

### 问题字段

```txt
62 61 69 64 75 03 63 6f 6d 00 00
                   query name            type   class
       --------------------------------  -----  -----
HEX    05 62 61 69 64 75 03 63 6f 6d 00  00 01  00 01
ASCII     b  a  i  d  u     c  o  m
DEC    5                 3           0       1      1
```

### 记录字段

```txt
c0 0c 00 01 00 01 00 00 00 3b 00 04 6f  3f 41 67
      name     type   class         ttl        len      ip
      ------  ------  ------  --------------  ------  --------------
HEX   c0  0c  00  01  00  01  00  00  00  3b  00  04  6f  3f  41  67
DEC   192 12    1       1           59          4     111 63  65  103
```

注意到 name 字段并没有存储实际的查询名称，比如 `baidu.com`。而是存储一个压缩指针。

- 0xc0（二进制 1100 0000）：高两位 11 表示这是一个压缩指针标签。
- 0x0c（十进制 12）：表示偏移量，即指向 DNS 报文起始位置的第 12 个字节。
